# Tubemint

**Tubemint** is a fully Python-based YouTube Video Inspector and Downloader built with **FastAPI**, **yt-dlp**, and **FFmpeg**.

---

## Features

- 🎥 **Video Metadata Extraction**: View video title, high-resolution thumbnail, and formatted duration.
- ⚙️ **Resolution Detection**: Automatically detects all available video quality levels (e.g. 1080p, 720p, 480p, 360p).
- ⚡ **Native Python Integration**: Uses the Python `yt-dlp` package for backend processing.
- 🎨 **Modern Interface**: Custom dark-mode theme styled with CSS glassmorphic cards, emerald accent colors, and responsive layout.

---

## Requirements

- Python 3.10+
- FFmpeg (installed and available on your system path)

---

## Quick Start

1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start the FastAPI application:
   ```bash
   python main.py
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8050
   ```
